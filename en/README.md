# Agentic Coding From Scratch

This booklet re-organizes the basics of software engineering for agentic coding.

## Why this booklet

With AI coding agents, people who have never studied software engineering can now build working software. But building software that keeps working, that can be changed, fixed, and trusted, still takes the basic knowledge that software engineers have built up over decades. The agent writes the code. Deciding what to build, how to split it up, how to tell whether it works, and how to keep it safe is still up to you.

This booklet re-organizes that basic knowledge from the point of view of agentic coding. Some topics matter more than before, because you now direct an agent instead of typing every line. Some matter less. And some are new, like how large language models (LLMs) and agentic systems work.

## Scope of this booklet

This booklet covers only things that **won't change unless there is another paradigm shift**. Tools, models, and services change every few months, so they are not the subject here. When the booklet mentions a specific tool, it is an example of an idea, not a recommendation to use that tool.

The booklet teaches by building. Along the way, we build an AI agent system, something like [Hermes Agent](https://github.com/NousResearch/hermes-agent) or [OpenClaw](https://github.com/openclaw/openclaw), using agentic coding. Each chapter explains a concept and then applies it to that agent. By the end, you will have built an agent system yourself, and you will know how the agents you use every day work inside.

Much of this booklet is the author's opinion. Anything without a reference is the author's opinion. Where there is a reference, I've cited it.

## Who is this booklet for?

I wrote this booklet for **non-engineers who want to become engineers**. I think it can help:

- People who build software with AI coding agents but have never studied software engineering
- Designers, planners, and researchers who want to build products themselves
- Anyone who wants to know how AI agents work inside
